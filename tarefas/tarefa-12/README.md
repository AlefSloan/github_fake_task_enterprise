# Tarefa 12

O catálogo interno precisa de pequenos ajustes antes de ser publicado.

## O que fazer

1. Corrija o nome do produto no arquivo `catalogo.txt`.
2. Corrija o valor de `estoque` no arquivo `catalogo.json` para `12`.
3. Crie o arquivo `publicacao.txt` com o texto `Catálogo pronto.`.

## Arquivos envolvidos

- `catalogo.txt`
- `catalogo.json`
- `publicacao.txt`

## Para passar na validação automática

- O arquivo `catalogo.txt` deve conter exatamente: `Produto: App Vendas Pro`
- No arquivo `catalogo.json`, o campo `estoque` deve ter o valor `12`.
- O arquivo `publicacao.txt` deve existir e conter exatamente: `Catálogo pronto.`
- Nenhum arquivo fora de `tarefas/tarefa-12` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.
