# Tarefa 19

O time de implantação validou um pequeno pacote de documentos.

## O que fazer

1. Corrija o nome do produto no arquivo `implantacao.txt`.
2. Crie o arquivo `check-in.txt` com o texto `Check-in realizado.`.
3. Renomeie `roteiro_implatacao.txt` para `roteiro_implantacao.txt`.

## Arquivos envolvidos

- `implantacao.txt`
- `check-in.txt`
- `roteiro_implatacao.txt`
- `roteiro_implantacao.txt`

## Para passar na validação automática

- O arquivo `implantacao.txt` deve conter exatamente: `Produto: Integra Fácil`
- O arquivo `check-in.txt` deve existir e conter exatamente: `Check-in realizado.`
- O arquivo `roteiro_implantacao.txt` deve existir e conter exatamente: `Roteiro de implantação.`
- O arquivo `roteiro_implatacao.txt` não deve mais existir neste local.
- Nenhum arquivo fora de `tarefas/tarefa-19` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.
