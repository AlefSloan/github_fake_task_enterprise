# Tarefa 25

O financeiro quer corrigir um resumo mensal simples.

## O que fazer

1. Corrija o resultado da conta no arquivo `mensal.txt`.
2. Corrija o título do arquivo `resumo.md` para Markdown com `#`.
3. Altere o status em `fechamento.txt` para `concluído`.

## Arquivos envolvidos

- `mensal.txt`
- `resumo.md`
- `fechamento.txt`

## Para passar na validação automática

- O arquivo `mensal.txt` deve conter exatamente: `40 + 2 = 42`
- O arquivo `resumo.md` deve conter exatamente: `# Resumo mensal`
- O arquivo `fechamento.txt` deve conter exatamente: `Status: concluído`
- Nenhum arquivo fora de `tarefas/tarefa-25` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.

## Lembrete

Mexa apenas nos arquivos desta tarefa. As outras pastas pertencem a outros colegas.
