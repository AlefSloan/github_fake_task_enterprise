# Tarefa 09

O setor comercial conferiu dados de uma proposta simples.

## O que fazer

1. Corrija o nome do cliente no arquivo `proposta.txt`.
2. Corrija o título do arquivo `resumo.md` para Markdown com `#`.
3. Crie o arquivo `aprovacao.txt` com o texto `Aprovação registrada.`.

## Arquivos envolvidos

- `proposta.txt`
- `resumo.md`
- `aprovacao.txt`

## Para passar na validação automática

- O arquivo `proposta.txt` deve conter exatamente: `Cliente: Beta Commerce`
- O arquivo `resumo.md` deve conter exatamente: `# Resumo da proposta`
- O arquivo `aprovacao.txt` deve existir e conter exatamente: `Aprovação registrada.`
- Nenhum arquivo fora de `tarefas/tarefa-09` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.

## Lembrete

Mexa apenas nos arquivos desta tarefa. As outras pastas pertencem a outros colegas.
