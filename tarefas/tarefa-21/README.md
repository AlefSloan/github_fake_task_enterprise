# Tarefa 21

O RH organizou informações de treinamento interno.

## O que fazer

1. Corrija o nome da instrutora no arquivo `instrutor.txt`.
2. Crie o arquivo `presenca.txt` com o texto `Presença confirmada.`.
3. Corrija o título do arquivo `treinamento.md` para Markdown com `#`.

## Arquivos envolvidos

- `instrutor.txt`
- `presenca.txt`
- `treinamento.md`

## Para passar na validação automática

- O arquivo `instrutor.txt` deve conter exatamente: `Instrutor: Carla Souza`
- O arquivo `presenca.txt` deve existir e conter exatamente: `Presença confirmada.`
- O arquivo `treinamento.md` deve conter exatamente: `# Treinamento interno`
- Nenhum arquivo fora de `tarefas/tarefa-21` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.
