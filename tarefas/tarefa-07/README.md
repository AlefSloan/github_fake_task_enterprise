# Tarefa 07

A equipe de suporte recebeu uma demanda de manutenção interna.

## O que fazer

1. Corrija o nome do cliente no arquivo `cliente.txt`.
2. Corrija o resultado da conta no arquivo `calculo.txt`.
3. Renomeie `relatorio_fevrero.txt` para `relatorio_fevereiro.txt`.

## Arquivos envolvidos

- `cliente.txt`
- `calculo.txt`
- `relatorio_fevrero.txt`
- `relatorio_fevereiro.txt`

## Para passar na validação automática

- O arquivo `cliente.txt` deve conter exatamente: `Cliente: Marina Costa`
- O arquivo `calculo.txt` deve conter exatamente: `7 + 6 = 13`
- O arquivo `relatorio_fevereiro.txt` deve existir e conter exatamente: `Relatório de fevereiro.`
- O arquivo `relatorio_fevrero.txt` não deve mais existir neste local.
- Nenhum arquivo fora de `tarefas/tarefa-07` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.
