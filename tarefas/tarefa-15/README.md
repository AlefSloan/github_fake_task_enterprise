# Tarefa 15

A diretoria pediu correções simples em dados internos.

## O que fazer

1. Corrija o nome do funcionário no arquivo `funcionario.txt`.
2. Corrija o resultado da conta no arquivo `calculo.txt`.
3. Corrija o valor de `ano` no arquivo `dados.json` para `2026`.

## Arquivos envolvidos

- `funcionario.txt`
- `calculo.txt`
- `dados.json`

## Para passar na validação automática

- O arquivo `funcionario.txt` deve conter exatamente: `Funcionário: Bruno Melo`
- O arquivo `calculo.txt` deve conter exatamente: `18 + 4 = 22`
- No arquivo `dados.json`, o campo `ano` deve ter o valor `2026`.
- Nenhum arquivo fora de `tarefas/tarefa-15` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.

## Lembrete

Mexa apenas nos arquivos desta tarefa. As outras pastas pertencem a outros colegas.
