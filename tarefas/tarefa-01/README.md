# Tarefa 01

A equipe de atendimento revisou documentos de um cliente piloto.

## O que fazer

1. Corrija o nome do cliente no arquivo `cliente.txt`.
2. Corrija o resultado da conta no arquivo `calculo.txt`.
3. Altere o status de `pendente` para `concluído` no arquivo `status.txt`.

## Arquivos envolvidos

- `cliente.txt`
- `calculo.txt`
- `status.txt`

## Para passar na validação automática

- O arquivo `cliente.txt` deve conter exatamente: `Cliente: Marina Costa`
- O arquivo `calculo.txt` deve conter exatamente: `12 + 8 = 20`
- O arquivo `status.txt` deve conter exatamente: `Status: concluído`
- Nenhum arquivo fora de `tarefas/tarefa-01` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.

## Lembrete

Mexa apenas nos arquivos desta tarefa. As outras pastas pertencem a outros colegas.
