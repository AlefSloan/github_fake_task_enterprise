# Tarefa 10

A gestão quer limpar pequenos erros em registros de sprint.

## O que fazer

1. Altere o status no arquivo `sprint.txt` para `concluído`.
2. Corrija o resultado da conta no arquivo `pontos.txt`.
3. Renomeie `planejamneto.txt` para `planejamento.txt`.

## Arquivos envolvidos

- `sprint.txt`
- `pontos.txt`
- `planejamneto.txt`
- `planejamento.txt`

## Para passar na validação automática

- O arquivo `sprint.txt` deve conter exatamente: `Status: concluído`
- O arquivo `pontos.txt` deve conter exatamente: `5 + 8 = 13`
- O arquivo `planejamento.txt` deve existir e conter exatamente: `Planejamento da sprint.`
- O arquivo `planejamneto.txt` não deve mais existir neste local.
- Nenhum arquivo fora de `tarefas/tarefa-10` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.

## Lembrete

Mexa apenas nos arquivos desta tarefa. As outras pastas pertencem a outros colegas.
