# Tarefa 02

O time de produto encontrou pequenas inconsistências no cadastro de um item.

## O que fazer

1. Renomeie `relatorio_janero.txt` para `relatorio_janeiro.txt`.
2. Corrija o nome do produto no arquivo `produto.txt`.
3. Corrija o valor de `preco` no arquivo `produto.json` para `59`.

## Arquivos envolvidos

- `relatorio_janero.txt`
- `relatorio_janeiro.txt`
- `produto.txt`
- `produto.json`

## Para passar na validação automática

- O arquivo `relatorio_janeiro.txt` deve existir e conter exatamente: `Relatório de janeiro.`
- O arquivo `relatorio_janero.txt` não deve mais existir neste local.
- O arquivo `produto.txt` deve conter exatamente: `Produto: Nuvem Box`
- No arquivo `produto.json`, o campo `preco` deve ter o valor `59`.
- Nenhum arquivo fora de `tarefas/tarefa-02` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.
