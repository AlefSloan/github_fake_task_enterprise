# Tarefa 30

O time de eventos precisa revisar um checklist enxuto.

## O que fazer

1. Corrija o título do arquivo `evento.md` para Markdown com `#`.
2. Crie o arquivo `local.txt` com o texto `Local confirmado.`.
3. Corrija o resultado da conta no arquivo `participantes.txt`.

## Arquivos envolvidos

- `evento.md`
- `local.txt`
- `participantes.txt`

## Para passar na validação automática

- O arquivo `evento.md` deve conter exatamente: `# Checklist do evento`
- O arquivo `local.txt` deve existir e conter exatamente: `Local confirmado.`
- O arquivo `participantes.txt` deve conter exatamente: `20 + 5 = 25`
- Nenhum arquivo fora de `tarefas/tarefa-30` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.

## Lembrete

Mexa apenas nos arquivos desta tarefa. As outras pastas pertencem a outros colegas.
