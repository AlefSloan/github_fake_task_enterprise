# Tarefa 33

O financeiro operacional revisou dados de reembolso.

## O que fazer

1. Corrija o resultado da conta no arquivo `reembolso.txt`.
2. Corrija o nome do funcionário no arquivo `funcionario.txt`.
3. Mova `entrada/recibo.txt` para `reembolsos/recibo.txt`.

## Arquivos envolvidos

- `reembolso.txt`
- `funcionario.txt`
- `entrada/recibo.txt`
- `reembolsos/recibo.txt`

## Para passar na validação automática

- O arquivo `reembolso.txt` deve conter exatamente: `60 + 15 = 75`
- O arquivo `funcionario.txt` deve conter exatamente: `Funcionário: Diego Rocha`
- O arquivo `reembolsos/recibo.txt` deve existir e conter exatamente: `Recibo de reembolso.`
- O arquivo `entrada/recibo.txt` não deve mais existir neste local.
- Nenhum arquivo fora de `tarefas/tarefa-33` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.
