# Tarefa 22

O time comercial precisa deixar uma proposta consistente.

## O que fazer

1. Corrija o nome do cliente no arquivo `cliente.txt`.
2. Corrija o resultado da conta no arquivo `desconto.txt`.
3. Corrija o valor de `validadeDias` no arquivo `proposta.json` para `15`.

## Arquivos envolvidos

- `cliente.txt`
- `desconto.txt`
- `proposta.json`

## Para passar na validação automática

- O arquivo `cliente.txt` deve conter exatamente: `Cliente: Delta Soluções`
- O arquivo `desconto.txt` deve conter exatamente: `100 - 15 = 85`
- No arquivo `proposta.json`, o campo `validadeDias` deve ter o valor `15`.
- Nenhum arquivo fora de `tarefas/tarefa-22` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.

## Lembrete

Mexa apenas nos arquivos desta tarefa. As outras pastas pertencem a outros colegas.
