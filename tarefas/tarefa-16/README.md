1. Altere o status em `chamado.txt` para `concluído`.

- `chamado.txt`
- `fechamento.txt`
- `cliente.txt`

- O arquivo `chamado.txt` deve conter exatamente: `Status: concluído`
- O arquivo `fechamento.txt` deve existir e conter exatamente: `Chamado fechado.`
- O arquivo `cliente.txt` deve conter exatamente: `Cliente: Atlas Serviços`
- Nenhum arquivo fora de `tarefas/tarefa-16` deve ser alterado.

A validação será feita automaticamente quando o Pull Request for aberto no GitHub.
